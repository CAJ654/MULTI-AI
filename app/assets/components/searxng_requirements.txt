# SearXNG has no PyPI package and no tagged releases -- it ships as a rolling
# CalVer+commit build off `master`. It is also an sdist (a setup.py, no
# pyproject.toml, no wheel), and the packaged app's *embeddable* Python cannot
# build an sdist: PEP 517 build isolation hands the scratch-installed setuptools
# to the build backend over PYTHONPATH, which python._pth makes the embeddable
# interpreter ignore (the same trap installer/runtime/bootstrap.py documents),
# so the build dies with "Cannot import 'setuptools.build_meta'" and pip exits 2.
#
# So searxng_install.py installs SearXNG in two halves that build nothing:
#   1. this file -- SearXNG's own pinned dependencies (all wheels), plus two
#      gaps in the embeddable interpreter: tzdata (it bundles no zoneinfo
#      database, and several engines construct ZoneInfo(...) at import) and
#      truststore (engines use httpx, which needs the OS trust store to work
#      behind the TLS-intercepting antivirus/proxies pip-system-certs already
#      covers for the main backend).
#   2. the `searx/` package, copied straight out of the archive named below.
#
# The dependency versions here are SearXNG's own requirements.txt at the pinned
# commit, copied verbatim. Pinned 2026-08-28. To move to a newer SearXNG: pick
# a `master` commit (https://github.com/searxng/searxng/commits/master), update
# the archive URL below AND re-copy the version pins from that commit's
# requirements.txt, then delete this component's .installed marker.
#
# archive: https://github.com/searxng/searxng/archive/a30b2d47492ab46ae82ce25ee62a31626565cf67.zip
